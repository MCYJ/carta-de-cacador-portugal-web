# Carta de Caçador Portugal Web

Public static marketing and study-information site for the independent Carta de Caçador Portugal app.

- Production: https://mcyj.github.io/carta-de-cacador-portugal-web/
- Build and validate: `python3 site.py && python3 check.py`
- Preview: `python3 -m http.server 8080 -d dist`
- Current ICNF procedure and exact public App Store ID `6801904047` checked 2026-10-23.
- App Store CTA is active; the Google Play package is not currently public.
- The site contains 18 indexable routes, including ten guides, FAQ and support/policy pages.
- Portuguese and English Store descriptions disagree on purchase details, so confirm terms in the current Store listing rather than publishing an inferred price or subscription.
- Original editorial dates remain in unchanged guides; revised factual/purchase-flow guides show 2026-10-23.

Articles are defined in `site.py`. Keep numeric exam claims linked to current official sources and never imply ICNF affiliation.
